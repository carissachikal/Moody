# Moodify

**Your mood, your story.**

A gentle, privacy-friendly mood tracker & journal that runs entirely in the browser.  
Check in daily, write short journal entries, see calendar & statistics, and get soft self-care suggestions.

## Live Demo
https://carissachikal.github.io/Moody/

## Features
- Daily mood check-in (7 moods + intensity + optional note)
- Mood calendar & weekly snapshot
- Simple statistics (dominant mood, frequency bars, average intensity)
- Journal entries (stored locally)
- Self-care suggestions based on mood
- Dark / light mode
- Fully client-side (data stays in your browser via `localStorage`)

## Tech
- Vanilla HTML, CSS, JavaScript
- No backend, no tracking, no accounts
- Deployed on GitHub Pages

## SEO & Assets
- `robots.txt` + `sitemap.xml`
- Open Graph & Twitter Card meta tags
- SVG favicon + web manifest

## Local development
Just open `index.html` in a browser or serve the folder with any static server.

```bash
npx serve .
```

## Note on “source protection”
Because this is a static site on GitHub Pages, the source is always public.  
The small client-side deterrents (right-click + common DevTools shortcuts) only raise the bar for casual inspection. They cannot truly hide the code.
